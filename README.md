## 1. Установка WSL и настройка Docker

Для выполнения практической работы я использовал WSL2 и Docker Desktop.

Сначала проверил, что Ubuntu работает через WSL2:

```bash
wsl.exe -l -v
```

Затем проверил установленный Docker:

```bash
docker version
```

После этого запустил тестовый контейнер:

```bash
docker run --rm hello-world
```

Docker успешно запустился и вывел сообщение `Hello from Docker!`.

## 2. Запуск готового сайта

Дальше я запустил готовый контейнер с Nginx:

```bash
docker run -d --name lab-web -p 127.0.0.1:8080:80 nginx:stable-alpine
```

После запуска проверил контейнер:

```bash
docker ps
```

Затем открыл в браузере:

`http://localhost:8080`

Открылся стандартный сайт Nginx с надписью `Welcome to nginx!`.

<!-- СЮДА ВСТАВИТЬ СКРИНШОТ 2: Welcome to nginx -->

Также проверил страницу, которой не существует:

`http://localhost:8080/missing`

В ответ получил ошибку `404 Not Found`.

<!-- СЮДА ВСТАВИТЬ СКРИНШОТ 3: ошибка 404 -->

После этого посмотрел логи контейнера:

```bash
docker logs lab-web
```

В логах были видны обращения к главной странице и к странице `/missing`.

## 3. Остановка и повторный запуск контейнера

Проверил, как работает остановка контейнера:

```bash
docker stop lab-web
```

После этого снова запустил его:

```bash
docker start lab-web
```

Проверил, что контейнер снова работает:

```bash
docker ps
```

## 4. Создание своего сайта

После проверки готового Nginx я создал свою папку для проекта:

```bash
mkdir -p ~/docker-lesson-01
cd ~/docker-lesson-01
```

В папке создал два основных файла:

- `index.html`
- `Dockerfile`

В `index.html` разместил свою страницу.

В `Dockerfile` указал, что за основу нужно взять Nginx и скопировать мой HTML-файл в папку сайта:

```dockerfile
FROM nginx:stable-alpine
COPY index.html /usr/share/nginx/html/index.html
```

## 5. Сборка первого Docker-образа

После создания файлов я собрал свой первый Docker-образ:

```bash
docker build -t student-site:v1 .
```

После успешной сборки запустил контейнер:

```bash
docker run -d --name my-site -p 127.0.0.1:8081:80 student-site:v1
```

После этого открыл сайт:

`http://localhost:8081`

На странице появилась первая версия моего сайта.

## 7. Запуск второго контейнера

Чтобы проверить, что несколько контейнеров могут работать независимо друг от друга, я запустил второй контейнер из версии `v2`:

```bash
docker run -d --name my-copy -p 127.0.0.1:8082:80 student-site:v2
```

После этого открыл:

`http://localhost:8082`

На странице также отображается моя вторая версия сайта.

<!-- СЮДА ВСТАВИТЬ СКРИНШОТ 8: второй контейнер на порту 8082 -->

Затем остановил первый контейнер:

```bash
docker stop my-site
```

При этом второй контейнер `my-copy` продолжил работать.

Таким образом, я проверил, что контейнеры работают независимо друг от друга.
